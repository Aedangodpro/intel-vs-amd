Pop-ups blocked? Allow them once — here's how
  1. Chrome / Edge: open this page, click the blocked-pop-up icon at the right of the address bar, choose Always allow pop-ups and redirects from this site, then press Done.
  2. Or settings: Privacy and security → Site settings → Pop-ups and redirects → Allowed to send pop-ups and use redirects → Add site and paste this page's address.
  3. Safari: Safari → Settings for This Website → Pop-up Windows: Allow.
  4. Firefox: click the blocked-pop-up bar → Options → Allow pop-ups for this site.
  5. Reload this page and press Open session once. If a school-managed profile blocks pop-ups by policy, use Open in this tab instead.
Tip: add ?stay=1 to this URL to stay on this page after the session opens.
